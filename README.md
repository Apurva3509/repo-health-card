# Repo Health Card

Repo Health Card is a small command-line tool and GitHub Action for producing
an actionable repository-maintenance report.

The first release will inspect public GitHub metadata and community-health
files, calculate a transparent score, and render the result as Markdown or
JSON.

## Roadmap

- Repository metadata and community-file checks
- Markdown and JSON reports
- GitHub Actions job-summary integration
- Configurable policies and score weights
